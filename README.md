# Weav3r Link Tracker

## Install

👉 [Click here to install](https://raw.githubusercontent.com/roxieraven327/Weav3r-Link-Tracker/main/weav3r-link-tracker.user.js)

(Requires Tampermonkey)

A lightweight Tampermonkey userscript for TornW3B Dollar Bazaars.

It adds a fading checkmark next to bazaar names you've clicked so you don’t accidentally keep opening the same links during a run.

## Features

- Marks clicked bazaar links with a ✓
- Checkmarks fade over time
- Auto-clears after 6 hours
- Lightweight and simple
- Supports Tampermonkey auto-updates

## Install

1. Install Tampermonkey.
2. Open the script file:
   `weav3r-link-tracker.user.js`
3. Click **Raw**.
4. Tampermonkey should open the install screen.
