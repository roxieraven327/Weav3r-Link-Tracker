## 🚀 Install

👉 **[Click here to install](https://raw.githubusercontent.com/roxieraven327/Weav3r-Link-Tracker/main/weav3r-link-tracker.user.js)**

If the install doesn’t trigger, open the link and click **Raw**.

---

## ✨ What it does

Adds a subtle ✓ next to bazaar names you've already clicked  
so you don’t waste time reopening the same ones.

## 🧠 Features

- ✓ Marks clicked bazaar links  
- ⏳ Fades over time  
- 🧹 Auto-clears after 6 hours  
- ⚡ Lightweight (no slowdown)  
- 🔄 Auto-updates via GitHub
